# Páginas web

**Herramientas:** HTML, CSS y JavaScript

- **San Arte:** sitio de catálogo y de contacto para el emprendimiento de un familiar. Página estática, sin servidor ni base de datos.
- **Rentable:** sitio de presentación y contacto para una empresa. En desarrollo.
- **Portafolio personal:** una página para presentar mis proyectos. En desarrollo.

Son sitios pensados para mostrar bien un negocio y facilitar el contacto, sin complicaciones técnicas para quien los administra.
